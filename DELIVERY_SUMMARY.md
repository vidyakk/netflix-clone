## 🚀 QUICK START (3 COMMANDS)

```bash
# 1. Install dependencies
cd backend && npm install && cd ../frontend && npm install

# 2. Start both servers (in separate terminals)
cd backend && npm run dev      # Terminal 1
cd frontend && npm start        # Terminal 2

# 3. Open in browser
http://localhost:3000
```
